# Retro Vault S.L. - Practica Odoo 17
Modulo de Sistemas de Gestion Empresarial (SGE)

## Descripcion del proyecto
Repositorio con la documentacion, configuracion y evidencias del despliegue de Odoo 17 para la empresa Retro Vault S.L., adaptado a Espana sin datos de prueba.

## Estructura del repositorio
- empresa/ : Ficha de empresa y catalogo de productos.
- instalacion/ : Guia de despliegue y errores de Docker.
- usuarios/ : Roles, principio de minimo privilegio y grupo personalizado.
- venta/ : Documentacion del ciclo comercial completo.
- capturas/ : Evidencias graficas de la practica.
